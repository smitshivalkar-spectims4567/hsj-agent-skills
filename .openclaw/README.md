# HSJ for OpenClaw

OpenClaw can consume the shared `AGENTS.md` contract and the Markdown skills in `skills/`. This adapter documents placement only; it does not modify `openclaw.json`, secrets, browser sessions, or tool permissions.

For a project-local setup, keep this repository beside the project and reference the needed skills from your OpenClaw workspace. Do not enable shell, network, browser, or MCP access merely because a skill mentions it.
