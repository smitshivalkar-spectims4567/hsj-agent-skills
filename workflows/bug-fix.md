# Bug Fix

1. Repository Explorer identifies the affected flow.
2. Debugger reproduces the issue and traces callers.
3. Technical Planner documents the root cause and fix.
4. Implementer makes a focused change.
5. Test Engineer adds or updates a regression check.
6. Code Reviewer verifies the fix and checks sibling callers.
7. Release Checker reports exact verification results.

Do not patch only the symptom when a shared root cause exists.
