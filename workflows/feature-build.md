# Feature Build

1. Repository Explorer maps the relevant code.
2. Requirements Clarifier writes acceptance criteria.
3. Technical Planner proposes the smallest change.
4. Human approves scope when ambiguity or risk exists.
5. Implementer executes the plan.
6. Test Engineer verifies acceptance criteria.
7. Code Reviewer reviews the diff.
8. Security Reviewer checks risk.
9. Release Checker produces the completion report.

Stop if requirements remain ambiguous, tests fail without an explanation, or a risky operation needs approval.
