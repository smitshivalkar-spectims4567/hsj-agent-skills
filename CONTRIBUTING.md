# Contributing to HSJ

Keep contributions focused and provider-neutral.

A new skill must include:

- Clear purpose and trigger conditions.
- Responsibilities and non-responsibilities.
- Required behavior.
- Output format.
- Failure and escalation behavior.
- At least one example.

Run the validator before opening a pull request:

```bash
python3 scripts/validate.py
```

Do not add an agent merely to increase the agent count. Add one when a repeated task has a clear boundary and a separate context improves reliability.
