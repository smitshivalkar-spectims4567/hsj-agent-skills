# Architecture Review

Evaluate a proposed design before it becomes expensive to change.

## Procedure
Describe constraints, data flow, boundaries, failure modes, security implications, operational cost, and alternatives. Prefer boring existing architecture. Identify the smallest reversible decision.

## Output
Decision, alternatives rejected, trade-offs, migration/rollback plan, and explicit approval required.
