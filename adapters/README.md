# HSJ adapters

HSJ keeps one canonical `skills/` directory and documents common coding-agent surfaces. Copy or link only what you need.

| Harness | Surface | Status |
|---|---|---|
| Claude Code | `CLAUDE.md`, `.claude-plugin/`, `.claude/skills/` | documented |
| Codex | `AGENTS.md`, `.codex-plugin/` | documented |
| Cursor | `.cursor/rules/` | documented |
| Gemini CLI | `GEMINI.md` | documented |
| Hermes | `.hermes/` | documented |
| OpenClaw | `.openclaw/` | documented |
| OpenCode | `.opencode/` | documented |
| Generic | `AGENTS.md`, `skills/` | documented |

Compatibility means documented placement, not identical feature support. HSJ does not install hooks, MCP servers, credentials, or permission changes automatically.
